# 하랑지점 팀 관리 — 사용 안내

주소: **https://api.insurguard.life/branch/**
로그인: 구글 계정으로 로그인합니다. 별도 가입·비밀번호가 없습니다.
(마이가디언에서 이미 승인된 계정이면 그대로 들어옵니다. 처음이면 총관리자 승인이 필요합니다.)

휴대폰에서도 같은 주소로 들어가면 됩니다. 브라우저 메뉴의 "홈 화면에 추가"를 하면
앱처럼 아이콘으로 열립니다.

## 화면 구성

**홈** — 접속하면 처음 보이는 화면입니다.
출석 체크 버튼, 오늘 내 일정, 오늘 팀 일정, 내 미션 달성률, 최신 공지가 한 판에 모여 있습니다.
공지는 여기서 바로 「확인」 버튼을 누를 수 있습니다.

**조직도** — 지점장 아래 부지점장이 팀의 단위입니다.
- 팀원 줄의 「수정」을 누르면 위 입력칸에 값이 채워집니다. 이름·직급·도입자를 고치고
  「수정 저장」을 누르면 됩니다. 「취소」로 되돌립니다.
- 팀 이름 변경·삭제는 각 팀 제목 옆 버튼에서 합니다 (총관리자·지점장). 소속 인원이 있는
  팀은 삭제되지 않습니다 — 인원을 먼저 옮깁니다.
- 총관리자·지점장은 전 팀을, 부지점장은 자기 팀을 수정합니다. 도입자를 지정하면 팀이 달라도
자기가 도입한 팀원의 일정을 볼 수 있습니다.
여기 등록한 명단이 일정·출석·업적 화면에 그대로 나열됩니다.

**일정** — 월간 달력이 기본입니다.
- 날짜를 누르면 그날 상세가 열리고, 거기서 바로 일정을 추가합니다.
- PC에서는 달력 칸을 직접 눌러도 그 자리에서 입력됩니다 (팀원·날짜는 칸이 정해줍니다).
- 입력 항목: 구분(상담·외근·교육·강의·면접 등) · 시간 · 내용 · 장소
- 화면 위 버튼으로 보기 범위를 바꿉니다.
  지점장·총관리자: 부지점장만 / 팀 전체 / 내 일정
  부지점장·팀원: 팀 전체 / 내 일정
- 「주간 확인표」 버튼을 누르면 팀원 전원의 한 주가 한 표에 나옵니다. 엑셀에서 여러 줄을
  복사해 붙여넣는 일괄 입력도 여기 있습니다.
- 구분을 **강의**로 하면 지점 전체 일정이 됩니다. 다른 팀원도 「신청」 버튼으로 참석 신청을
  할 수 있고, 강사에게 신청 인원과 명단이 보입니다.

**일일보고** — 카톡으로 보내던 일일보고를 여기서 씁니다.
- 출근 상태 · 오전 활동 · 점심 일정 · 오후 활동 · 특이사항을 채웁니다.
- 이번 달 목표와 현재 CANP는 업적 자료에서 자동으로 붙습니다 (직접 적지 않습니다).
- 「카톡 문구 복사」를 누르면 지금까지 쓰던 형식 그대로 복사됩니다. 카톡에 붙여넣기만 하면 됩니다.
- 저녁 6시 이후에 열면 자동으로 다음 날 보고가 잡힙니다 (전날 저녁에 쓰는 습관 그대로).
- 아래 팀 현황 표에서 팀원 전원의 보고를 한눈에 봅니다. 출석·보고 인원이 집계됩니다.

**미션·공지**
- 부지점장이 팀원 개인 미션·팀 미션을 부여합니다 (제목·내용·기한).
- 각자 「달성」 버튼을 누르면 달성률이 퍼센트로 올라갑니다. 팀 미션은 달성 인원 / 팀 인원입니다.
- 공지는 팀 공지와 지점 전체 공지로 나뉩니다. 댓글 대신 「확인」 버튼 한 번이면 됩니다.

**TA 일지** — 통화 한 건이 한 줄입니다. 엑셀에서 범위를 복사해 그대로 붙여넣을 수 있습니다.
마지막 줄에서 Enter를 누르면 새 줄이 생깁니다. 담당자별 활동량은 자동으로 집계됩니다.

**업적현황** — 팀별로 합계(건수·월납·CANP·도입)가 나오고, 그 아래 팀원별 계약이 나열됩니다.
본인 계약은 본인이, 또는 부지점장이 대신 입력합니다. 목표와 도입 인원은 부지점장이 입력합니다.

## 팀원 초대

조직도 화면의 「팀원 초대」에서 직급을 고르고 **초대 문구 만들기 → 카톡 문구 복사**를 누르면
초대 링크가 담긴 문구가 복사됩니다. 카톡으로 그대로 보내면 됩니다.

- 초대는 **팀원 누구나** 만들 수 있습니다. 초대 자체로 권한이 생기지는 않습니다.
- 초대받은 사람이 링크를 눌러 회사 구글 계정으로 로그인하면 **승인 대기**로 접수됩니다.
- 승인은 **지점장·부지점장·총관리자**가 합니다. 조직도 화면 맨 위에 대기 목록이 뜨고,
  「승인」을 누르면 그 즉시 조직도에 들어가고 이용이 열립니다.
- 초대 링크는 14일 뒤 만료됩니다.
